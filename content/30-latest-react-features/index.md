Interviewers love asking "what's new in React?" to check whether you keep up. This section covers every major addition from React 19 (December 2024) through React 19.1, 19.2 and 19.3 (September 2026), plus the React Compiler. Each page explains one feature: what problem it solves, how to use it, and the mistakes people make with it. Start with the overview, then go deep on the ones your target role uses most.
